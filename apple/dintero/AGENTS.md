This app reads Dintero settlements and ReAI bank transactions only when the user clicks Review. A user may explicitly create one monthly manual fee voucher, flagged for review. Keep settlement IDs visible, never post sales or VAT automatically, and validate the clearing and expense accounts against ReAI before posting. Require explicit confirmation that the payout fees are withheld and not already invoiced or booked. Check existing vouchers before retrying a write. Store Dintero and ReAI secrets only in this app's Keychain service. Build with Swift 6.4 via `python3 tools/apple/build.py dintero`.
