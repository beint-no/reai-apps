## How Switch from Fiken to ReAI works with ReAI

Use **Switch from Fiken to ReAI** directly in your browser at `apps.reai.no/app/fiken-migrate/` with zero add-on fees.

| Dimension | Details |
| --- | --- |
| **Workflow** | Accounting migration (Fiken -> ReAI) |
| **ReAI API / NS 4102** | `Fiken API v2 -> POST /api/customers, /api/suppliers, /api/products` |
| **Authentication** | Browser approval via ReAI with encrypted `HttpOnly` session cookie |
| **License & price** | Free with ReAI · MIT open source (`web/worker/apps/switchers.js`) |

## Getting started

1. Open [apps.reai.no/app/fiken-migrate/](/app/fiken-migrate/) and click **Connect to ReAI**.
2. Try the built-in **Load sample** button or connect your live account/export.
3. Verify the preview table and push directly to your ReAI company.
