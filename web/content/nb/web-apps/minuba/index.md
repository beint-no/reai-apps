## Slik kobler du Minuba til ReAI uten tilleggskostnad

Mange norske bedrifter betaler flere hundre kroner i måneden for eksterne integrasjonsbroer mellom **Minuba** og regnskapssystemet. Med ReAI er koblingen gratis, åpen (MIT-lisens) og kjører rett i nettleseren på `apps.reai.no/app/minuba/`.

| Område | Oppsett i ReAI |
| --- | --- |
| Bransje | Cloud trades order management (Håndverk) |
| Kontoplan / API | `3000 / Orders` |
| Kontroll og sikkerhet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang på 2 minutter

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Prøv gjerne **Load sample** først for å se hvordan bilaget eller synken ser ut i ReAI.
3. Last opp eksporten din eller legg inn tallene/API-tilgangen fra Minuba og overfør direkte til ReAI.
