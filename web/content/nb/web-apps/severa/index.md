## Gratis integrasjon mellom Severa og ReAI

Koble **Severa** rett til ReAI i nettleseren på `apps.reai.no/app/severa/` uten dyre månedsgebyrer for eksterne integrasjonsbroer.

| Område | Detaljer |
| --- | --- |
| Bransje | Consulting & professional services (Konsulent) |
| Kontoplan / API | `POST /api/timesheets` |
| Trygghet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Klikk **Load sample** for å teste hvordan bilaget eller synken ser ut umiddelbart.
3. Last opp eksporten fra Severa eller legg inn tall/API-nøkkel for å overføre direkte til ReAI.
