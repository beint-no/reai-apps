## Slik fungerer SaaS MRR / ARR og abonnementsfakturering med ReAI

Bruk **SaaS MRR / ARR og abonnementsfakturering** rett i nettleseren på `apps.reai.no/app/mrr/` uten ekstra månedlige koblingsgebyrer.

| Område | Detaljer |
| --- | --- |
| **Bruksområde** | SaaS, retainers & recurring billing |
| **ReAI API / NS 4102** | `GET /api/subscriptions & POST /api/subscriptions/generate-due` |
| **Innlogging** | Nettlesergodkjenning i ReAI med kryptert `HttpOnly`-økt |
| **Lisens og pris** | Gratis med ReAI · MIT åpen kildekode (`web/worker/apps/mrr.js`) |

## Kom i gang på 2 minutter

1. Åpne [apps.reai.no/app/mrr/](/app/mrr/) og klikk **Connect to ReAI**.
2. Test først med **Load sample**, eller koble til eksport/API fra systemet ditt.
3. Kontroller forhåndsvisningen og send direkte inn i ReAI.
