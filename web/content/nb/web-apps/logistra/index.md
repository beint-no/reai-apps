## Gratis integrasjon mellom Logistra og ReAI

Koble **Logistra** rett til ReAI i nettleseren på `apps.reai.no/app/logistra/` uten dyre månedsgebyrer for eksterne integrasjonsbroer.

| Område | Detaljer |
| --- | --- |
| Bransje | Ecommerce & wholesale shipping (EDI-frakt) |
| Kontoplan / API | `POST /api/orders` |
| Trygghet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Klikk **Load sample** for å teste hvordan bilaget eller synken ser ut umiddelbart.
3. Last opp eksporten fra Logistra eller legg inn tall/API-nøkkel for å overføre direkte til ReAI.
