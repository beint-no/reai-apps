## Slik fungerer Integrasjon mellom Fresha og regnskap med ReAI

Bruk **Integrasjon mellom Fresha og regnskap** rett i nettleseren på `apps.reai.no/app/fresha/` uten ekstra månedlige koblingsgebyrer.

| Område | Detaljer |
| --- | --- |
| **Bruksområde** | Salons, barbershops & beauty studios |
| **ReAI API / NS 4102** | `1580 / 7770 / 3000+2700 / 3100 review vouchers` |
| **Innlogging** | Nettlesergodkjenning i ReAI med kryptert `HttpOnly`-økt |
| **Lisens og pris** | Gratis med ReAI · MIT åpen kildekode (`web/worker/apps/norway-deep.js`) |

## Kom i gang på 2 minutter

1. Åpne [apps.reai.no/app/fresha/](/app/fresha/) og klikk **Connect to ReAI**.
2. Test først med **Load sample**, eller koble til eksport/API fra systemet ditt.
3. Kontroller forhåndsvisningen og send direkte inn i ReAI.
