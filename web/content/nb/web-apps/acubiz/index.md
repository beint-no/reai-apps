## Gratis integrasjon mellom Acubiz og ReAI

Koble **Acubiz** rett til ReAI i nettleseren på `apps.reai.no/app/acubiz/` uten dyre månedsgebyrer for eksterne integrasjonsbroer.

| Område | Detaljer |
| --- | --- |
| Bransje | Corporate travel & expenses (Utlegg) |
| Kontoplan / API | `7140, 6800, 2915` |
| Trygghet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Klikk **Load sample** for å teste hvordan bilaget eller synken ser ut umiddelbart.
3. Last opp eksporten fra Acubiz eller legg inn tall/API-nøkkel for å overføre direkte til ReAI.
