## Slik kobler du Opus Dental til ReAI uten tilleggskostnad

Mange norske bedrifter betaler flere hundre kroner i måneden for eksterne integrasjonsbroer mellom **Opus Dental** og regnskapssystemet. Med ReAI er koblingen gratis, åpen (MIT-lisens) og kjører rett i nettleseren på `apps.reai.no/app/opus-dental/`.

| Område | Oppsett i ReAI |
| --- | --- |
| Bransje | Dental clinics & HELFO (Tannklinikk) |
| Kontoplan / API | `1580, 1570 (HELFO), 3100, 3000` |
| Kontroll og sikkerhet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang på 2 minutter

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Prøv gjerne **Load sample** først for å se hvordan bilaget eller synken ser ut i ReAI.
3. Last opp eksporten din eller legg inn tallene/API-tilgangen fra Opus Dental og overfør direkte til ReAI.
