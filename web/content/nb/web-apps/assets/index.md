## Slik fungerer Anleggsmidler og saldoavskrivning med ReAI

Bruk **Anleggsmidler og saldoavskrivning** rett i nettleseren på `apps.reai.no/app/assets/` uten ekstra månedlige koblingsgebyrer.

| Område | Detaljer |
| --- | --- |
| **Bruksområde** | Fixed asset register & depreciation |
| **ReAI API / NS 4102** | `POST /api/assets & GET /api/assets` |
| **Innlogging** | Nettlesergodkjenning i ReAI med kryptert `HttpOnly`-økt |
| **Lisens og pris** | Gratis med ReAI · MIT åpen kildekode (`web/worker/apps/reai-power.js`) |

## Kom i gang på 2 minutter

1. Åpne [apps.reai.no/app/assets/](/app/assets/) og klikk **Connect to ReAI**.
2. Test først med **Load sample**, eller koble til eksport/API fra systemet ditt.
3. Kontroller forhåndsvisningen og send direkte inn i ReAI.
