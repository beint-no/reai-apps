## Gratis integrasjon mellom Husleie.no og ReAI

Koble **Husleie.no** rett til ReAI i nettleseren på `apps.reai.no/app/husleie/` uten dyre månedsgebyrer for eksterne integrasjonsbroer.

| Område | Detaljer |
| --- | --- |
| Bransje | Residential landlords (Boligutleie) |
| Kontoplan / API | `POST /api/subscriptions` |
| Trygghet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Klikk **Load sample** for å teste hvordan bilaget eller synken ser ut umiddelbart.
3. Last opp eksporten fra Husleie.no eller legg inn tall/API-nøkkel for å overføre direkte til ReAI.
