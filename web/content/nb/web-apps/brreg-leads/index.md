## Slik fungerer Brønnøysund Enhetssøk til ReAI Leads med ReAI

Bruk **Brønnøysund Enhetssøk til ReAI Leads** rett i nettleseren på `apps.reai.no/app/brreg-leads/` uten ekstra månedlige koblingsgebyrer.

| Område | Detaljer |
| --- | --- |
| **Bruksområde** | B2B sales & prospecting (Enhetsregisteret) |
| **ReAI API / NS 4102** | `Live data.brreg.no API -> POST /api/leads` |
| **Innlogging** | Nettlesergodkjenning i ReAI med kryptert `HttpOnly`-økt |
| **Lisens og pris** | Gratis med ReAI · MIT åpen kildekode (`web/worker/apps/reai-power.js`) |

## Kom i gang på 2 minutter

3. Kontroller forhåndsvisningen og send direkte inn i ReAI.
