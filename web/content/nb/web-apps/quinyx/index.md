## Gratis integrasjon mellom Quinyx og ReAI

Koble **Quinyx** rett til ReAI i nettleseren på `apps.reai.no/app/quinyx/` uten dyre månedsgebyrer for eksterne integrasjonsbroer.

| Område | Detaljer |
| --- | --- |
| Bransje | Enterprise retail & hospitality WFM (Turnus) |
| Kontoplan / API | `POST /api/timesheets` |
| Trygghet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Klikk **Load sample** for å teste hvordan bilaget eller synken ser ut umiddelbart.
3. Last opp eksporten fra Quinyx eller legg inn tall/API-nøkkel for å overføre direkte til ReAI.
