## Gratis integrasjon mellom AutoNet og ReAI

Koble **AutoNet** rett til ReAI i nettleseren på `apps.reai.no/app/autonet/` uten dyre månedsgebyrer for eksterne integrasjonsbroer.

| Område | Detaljer |
| --- | --- |
| Bransje | Car workshops & auto dealers (Bilverksted) |
| Kontoplan / API | `POST /api/orders` |
| Trygghet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Klikk **Load sample** for å teste hvordan bilaget eller synken ser ut umiddelbart.
3. Last opp eksporten fra AutoNet eller legg inn tall/API-nøkkel for å overføre direkte til ReAI.
