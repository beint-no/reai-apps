## Slik fungerer Regnskapsfører klientoversikt med ReAI

Bruk **Regnskapsfører klientoversikt** rett i nettleseren på `apps.reai.no/app/accountant-hub/` uten ekstra månedlige koblingsgebyrer.

| Område | Detaljer |
| --- | --- |
| **Bruksområde** | Norwegian accounting firms (Regnskapsfører) |
| **ReAI API / NS 4102** | `GET /api/accountant-clients` |
| **Innlogging** | Nettlesergodkjenning i ReAI med kryptert `HttpOnly`-økt |
| **Lisens og pris** | Gratis med ReAI · MIT åpen kildekode (`web/worker/apps/reai-power.js`) |

## Kom i gang på 2 minutter

1. Åpne [apps.reai.no/app/accountant-hub/](/app/accountant-hub/) og klikk **Connect to ReAI**.
2. Test først med **Load sample**, eller koble til eksport/API fra systemet ditt.
3. Kontroller forhåndsvisningen og send direkte inn i ReAI.
