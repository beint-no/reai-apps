## Slik fungerer Make, Zapier og n8n integrasjonshub med ReAI

Bruk **Make, Zapier og n8n integrasjonshub** rett i nettleseren på `apps.reai.no/app/automations/` uten ekstra månedlige koblingsgebyrer.

| Område | Detaljer |
| --- | --- |
| **Bruksområde** | No-code & low-code workflow automation |
| **ReAI API / NS 4102** | `ReAI Public REST API (/api/customers, /api/orders, /api/leads)` |
| **Innlogging** | Nettlesergodkjenning i ReAI med kryptert `HttpOnly`-økt |
| **Lisens og pris** | Gratis med ReAI · MIT åpen kildekode (`web/worker/apps/automations.js`) |

## Kom i gang på 2 minutter

1. Åpne [apps.reai.no/app/automations/](/app/automations/) og klikk **Connect to ReAI**.
2. Test først med **Load sample**, eller koble til eksport/API fra systemet ditt.
3. Kontroller forhåndsvisningen og send direkte inn i ReAI.
