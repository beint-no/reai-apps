## Gratis integrasjon mellom Simployer og ReAI

Koble **Simployer** rett til ReAI i nettleseren på `apps.reai.no/app/simployer/` uten dyre månedsgebyrer for eksterne integrasjonsbroer.

| Område | Detaljer |
| --- | --- |
| Bransje | Norwegian HR & travel claims (Reiseregning) |
| Kontoplan / API | `7140, 7150, 2915` |
| Trygghet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Klikk **Load sample** for å teste hvordan bilaget eller synken ser ut umiddelbart.
3. Last opp eksporten fra Simployer eller legg inn tall/API-nøkkel for å overføre direkte til ReAI.
