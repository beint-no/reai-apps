## Slik kobler du Checkin til ReAI uten tilleggskostnad

Mange norske bedrifter betaler flere hundre kroner i måneden for eksterne integrasjonsbroer mellom **Checkin** og regnskapssystemet. Med ReAI er koblingen gratis, åpen (MIT-lisens) og kjører rett i nettleseren på `apps.reai.no/app/checkin/`.

| Område | Oppsett i ReAI |
| --- | --- |
| Bransje | Courses, conferences & seminars (Kurs og konferanse) |
| Kontoplan / API | `3100 (0%), 3000 (25%), 7770` |
| Kontroll og sikkerhet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang på 2 minutter

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Prøv gjerne **Load sample** først for å se hvordan bilaget eller synken ser ut i ReAI.
3. Last opp eksporten din eller legg inn tallene/API-tilgangen fra Checkin og overfør direkte til ReAI.
