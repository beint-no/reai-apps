## Slik fungerer Bytt fra Tripletex til ReAI med ReAI

Bruk **Bytt fra Tripletex til ReAI** rett i nettleseren på `apps.reai.no/app/tripletex-migrate/` uten ekstra månedlige koblingsgebyrer.

| Område | Detaljer |
| --- | --- |
| **Bruksområde** | Accounting migration (Tripletex -> ReAI) |
| **ReAI API / NS 4102** | `Tripletex v2 API -> POST /api/customers, /api/suppliers, /api/products` |
| **Innlogging** | Nettlesergodkjenning i ReAI med kryptert `HttpOnly`-økt |
| **Lisens og pris** | Gratis med ReAI · MIT åpen kildekode (`web/worker/apps/tripletex-migrate.js`) |

## Kom i gang på 2 minutter

1. Åpne [apps.reai.no/app/tripletex-migrate/](/app/tripletex-migrate/) og klikk **Connect to ReAI**.
2. Test først med **Load sample**, eller koble til eksport/API fra systemet ditt.
3. Kontroller forhåndsvisningen og send direkte inn i ReAI.
