## Gratis integrasjon mellom Hoopla og ReAI

Koble **Hoopla** rett til ReAI i nettleseren på `apps.reai.no/app/hoopla/` uten dyre månedsgebyrer for eksterne integrasjonsbroer.

| Område | Detaljer |
| --- | --- |
| Bransje | Concerts, festivals & races (Billettsalg) |
| Kontoplan / API | `3100 (0%), 3000 (25%), 7770` |
| Trygghet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Klikk **Load sample** for å teste hvordan bilaget eller synken ser ut umiddelbart.
3. Last opp eksporten fra Hoopla eller legg inn tall/API-nøkkel for å overføre direkte til ReAI.
