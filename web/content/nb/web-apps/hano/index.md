## Gratis integrasjon mellom Hano og ReAI

Koble **Hano** rett til ReAI i nettleseren på `apps.reai.no/app/hano/` uten dyre månedsgebyrer for eksterne integrasjonsbroer.

| Område | Detaljer |
| --- | --- |
| Bransje | Salons, spas & clinics (Salong og spa) |
| Kontoplan / API | `1580, 3100 (0%), 3000 (25%)` |
| Trygghet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Klikk **Load sample** for å teste hvordan bilaget eller synken ser ut umiddelbart.
3. Last opp eksporten fra Hano eller legg inn tall/API-nøkkel for å overføre direkte til ReAI.
