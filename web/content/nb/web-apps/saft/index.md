## Gratis integrasjon mellom SAF-T NO og ReAI

Koble **SAF-T NO** rett til ReAI i nettleseren på `apps.reai.no/app/saft/` uten dyre månedsgebyrer for eksterne integrasjonsbroer.

| Område | Detaljer |
| --- | --- |
| Bransje | Switching Norwegian accounting systems (SAF-T) |
| Kontoplan / API | `SAF-T XML -> Customers, Suppliers & Trial Balance` |
| Trygghet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Klikk **Load sample** for å teste hvordan bilaget eller synken ser ut umiddelbart.
3. Last opp eksporten fra SAF-T NO eller legg inn tall/API-nøkkel for å overføre direkte til ReAI.
