## Gratis integrasjon mellom PasientSky og ReAI

Koble **PasientSky** rett til ReAI i nettleseren på `apps.reai.no/app/pasientsky/` uten dyre månedsgebyrer for eksterne integrasjonsbroer.

| Område | Detaljer |
| --- | --- |
| Bransje | Medical clinics & specialists (Klinikk og HELFO) |
| Kontoplan / API | `1580, 1570 (HELFO), 3100` |
| Trygghet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Klikk **Load sample** for å teste hvordan bilaget eller synken ser ut umiddelbart.
3. Last opp eksporten fra PasientSky eller legg inn tall/API-nøkkel for å overføre direkte til ReAI.
