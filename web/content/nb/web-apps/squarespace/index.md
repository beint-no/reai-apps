## Gratis integrasjon mellom Squarespace og ReAI

Koble **Squarespace** rett til ReAI i nettleseren på `apps.reai.no/app/squarespace/` uten dyre månedsgebyrer for eksterne integrasjonsbroer.

| Område | Detaljer |
| --- | --- |
| Bransje | Design & DTC online stores (Nettbutikk) |
| Kontoplan / API | `Commerce REST API -> ReAI` |
| Trygghet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Klikk **Load sample** for å teste hvordan bilaget eller synken ser ut umiddelbart.
3. Last opp eksporten fra Squarespace eller legg inn tall/API-nøkkel for å overføre direkte til ReAI.
