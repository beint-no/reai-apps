## Gratis integrasjon mellom Airbnb og ReAI

Koble **Airbnb** rett til ReAI i nettleseren på `apps.reai.no/app/airbnb/` uten dyre månedsgebyrer for eksterne integrasjonsbroer.

| Område | Detaljer |
| --- | --- |
| Bransje | Short-term rental hosts & cabin operators (Korttidsutleie) |
| Kontoplan / API | `3020 (12%), 3100 (0%), 7770` |
| Trygghet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Klikk **Load sample** for å teste hvordan bilaget eller synken ser ut umiddelbart.
3. Last opp eksporten fra Airbnb eller legg inn tall/API-nøkkel for å overføre direkte til ReAI.
