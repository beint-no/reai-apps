## Gratis integrasjon mellom Opter TMS og ReAI

Koble **Opter TMS** rett til ReAI i nettleseren på `apps.reai.no/app/opter/` uten dyre månedsgebyrer for eksterne integrasjonsbroer.

| Område | Detaljer |
| --- | --- |
| Bransje | Transport, couriers & distribution (Transport) |
| Kontoplan / API | `POST /api/orders` |
| Trygghet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Klikk **Load sample** for å teste hvordan bilaget eller synken ser ut umiddelbart.
3. Last opp eksporten fra Opter TMS eller legg inn tall/API-nøkkel for å overføre direkte til ReAI.
