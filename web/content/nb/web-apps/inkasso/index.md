## Gratis integrasjon mellom Inkasso NO og ReAI

Koble **Inkasso NO** rett til ReAI i nettleseren på `apps.reai.no/app/inkasso/` uten dyre månedsgebyrer for eksterne integrasjonsbroer.

| Område | Detaljer |
| --- | --- |
| Bransje | Norwegian debt collection (Inkasso) |
| Kontoplan / API | `1580, 1579, 8050, 7770` |
| Trygghet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Klikk **Load sample** for å teste hvordan bilaget eller synken ser ut umiddelbart.
3. Last opp eksporten fra Inkasso NO eller legg inn tall/API-nøkkel for å overføre direkte til ReAI.
