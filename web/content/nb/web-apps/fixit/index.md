## Gratis integrasjon mellom Fixit og ReAI

Koble **Fixit** rett til ReAI i nettleseren på `apps.reai.no/app/fixit/` uten dyre månedsgebyrer for eksterne integrasjonsbroer.

| Område | Detaljer |
| --- | --- |
| Bransje | Hair salons & beauty studios (Frisør) |
| Kontoplan / API | `1580, 1900, 3000 (25%), 7770` |
| Trygghet | Forhåndsvisning før bokføring, duplikatsperre og kontrollbilag |

## Kom i gang

1. Klikk **Åpne integrasjon** over og koble til ReAI-selskapet ditt.
2. Klikk **Load sample** for å teste hvordan bilaget eller synken ser ut umiddelbart.
3. Last opp eksporten fra Fixit eller legg inn tall/API-nøkkel for å overføre direkte til ReAI.
