GET STARTED

Download. Connect. Work.

Most apps need only ReAI browser approval. Stripe Import also takes a restricted Stripe read key.

  1. 01

    Install

    Mac: open the disk image and drag the app to Applications.
    Windows: extract the whole ZIP and open the app’s EXE.

  2. 02

    Connect to ReAI

    Sign in in your browser, compare the code, choose a company and approve.

  3. 03

    Start working

    The app uses your existing permissions in the company you selected.

Windows downloads

Choose x64 for Intel/AMD PCs or ARM64 for ARM-based PCs. Check Settings → System → About → System type. Extract the whole ZIP before opening the app; no build tools or administrator access are needed.

These apps are unsigned. If SmartScreen offers More info → Run anyway, you can choose it after confirming the download is from our GitHub repository and you trust it. Smart App Control, S mode or workplace policy may block the app with no per-app override. Keep Windows security protections enabled.

To update, close the app and extract the new version into a new folder. Your connection and app data stay in your Windows user profile.

Your password stays in the browser. Access keys stay in macOS Keychain or Windows Credential Locker.
Revoke an app’s access at any time in your ReAI profile.
